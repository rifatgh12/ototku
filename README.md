# 🏋️‍♂️ OtotKu — Tracker Makan & Latihan Gym (PWA + Cloud Sync)

🔗 **Buka Aplikasi (Live GitHub Pages):** **[https://rifatgh12.github.io/ototku/](https://rifatgh12.github.io/ototku/)**

Aplikasi web progresif (**PWA**) untuk memantau asupan **protein, kalori, lemak jenuh, biaya makan harian**, serta **progres latihan gym (dumbbell 4 hari/minggu)** dengan **Database Cloud Terintegrasi** agar otomatis tersinkronisasi antara Laptop dan Handphone.

## ✨ Fitur Utama
- ☁️ **Database Cloud Terintegrasi Otomatis:** Langsung terhubung antara PC/Laptop dan HP tanpa perlu setup rumit.
- 🍽️ **Tracker Makan & Anggaran:** Pantau protein, kalori, lemak jenuh, dan biaya makan harian/mingguan/bulanan.
- 🏋️ **Tracker Gym & Progressive Overload:** Jadwal latihan 4 hari/minggu lengkap dengan panduan foto & video gerakan, timer istirahat otomatis, dan rekomendasi kenaikan beban.
- 📈 **Grafik Progres:** Visualisasi berat badan, lingkar tubuh, asupan protein/kalori, beban angkatan maksimal, dan pengeluaran.
- 📲 **Instal sebagai Aplikasi HP (PWA):** Mendukung instalasi di Android & iOS serta mode offline.
